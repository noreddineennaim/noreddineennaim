## 🚀 Featured Projects

### 🎙️ [DubNour — AI Video Dubbing & TTS Studio](https://github.com/noreddineennaim/DubNour-AI-Video-Dubbing-TTS-Studio)

> **Desktop application for video recap dubbing, storytelling, and multi-language AI audio generation using Google Gemini TTS, ElevenLabs, and FFmpeg.**

```
MP4 Video ➔ JSON Timings ➔ FFmpeg Split ➔ Gemini / ElevenLabs TTS ➔ AI Audio Generation ➔ Final Dubbed MP4
```

- **Dual AI Speech Engines**: Switch dynamically between **Google Gemini TTS** and **ElevenLabs TTS** with customizable voice models, speed controls (`0.5x`–`2.0x`), and emotional prompt prosody.
- **FFmpeg Frame Precision**: Video segmentation with **Accurate** (frame-precise re-encoding) or **Fast** (stream copy keyframe) modes.
- **Sequential Processing & Resilience**: Pause, resume, retry failed voiceover segments, and view real-time audio status.
- **Secure Credentials**: Native OS keychain integration via `keytar` alongside `.env` support.
- **Tech Stack**: Electron, React 18, TypeScript, Vite, FFmpeg, Google Gemini API, ElevenLabs API.
